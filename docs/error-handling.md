# エラーハンドリング・フォールバック方針

## 外部API障害時のフォールバック

### 天候API（Open-Meteo）

- 障害・タイムアウト時は**晴れ扱いとして表示する**
- エラーメッセージ等はユーザーに表に出さず、違和感なく表示を継続する

## 位置情報が取得できない場合

- Cloudflare `request.cf`からも位置情報が得られない稀なケースでは、**東京基準**のデフォルト地域にフォールバックする
  - 対象ユーザーが日本語話者中心であるため、最も無難なデフォルトとする

## JavaScriptエラー・クラッシュ対策

- React の **Error Boundary** を機能単位（背景アニメーション、カウントダウン、プログレスバー等）で設置し、一部の機能がクラッシュしてもページ全体が白画面にならないようにする
- 各Error Boundaryは、クラッシュ時に最低限の表示（例: 該当エリアを非表示にする、簡易なフォールバックUIを出す）に切り替える
