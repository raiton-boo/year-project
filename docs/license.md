# ライセンス・法務面の方針

## 利用素材のライセンス確認

本サイトでは以下の外部素材・ツールを利用する想定であり、いずれも**利用前にライセンス・商用利用可否を本人が確認する**。

| 素材・ツール                     | 用途                                                                | 確認事項                                                                                                 |
| -------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| LottieFiles（無料素材）          | 特定の日の主役キャラクター演出（`feature/background-animation.md`） | 商用利用可否、クレジット表記義務の有無                                                                   |
| AI画像生成ツール（Midjourney等） | OG画像・背景イラスト（`feature/og-image.md`）                       | 生成物の商用利用・公開可否（利用するツールの規約は都度変わるため、制作開始前に必ず最新の規約を確認する） |

## クレジット表記

- クレジット表記は、**利用する素材のライセンスが表記を義務付けている場合のみ**、フッター等に軽く記載する
- 専用のクレジットページは設けない（MVPの範囲外）

## プライバシーポリシー

### 方針

- 本サイトは氏名・メールアドレス・アカウント情報等、個人を特定できる情報は収集・保存しない（Cookie不要のCloudflare Web Analytics、リクエスト処理中のみ一時利用するIPベース位置情報、ブラウザ側の許可フローを伴うGeolocation API）
- そのため、日本の個人情報保護法上プライバシーポリシーの掲示が法的に必須となる水準のデータ収集は行っていないと考えられる
- とはいえ、閲覧者の信頼感のため、**簡易な注記ページ（数行程度）を追加する**
  - 内容イメージ: 利用している解析ツール（Cloudflare Web Analytics）、位置情報の用途（天候・天体アニメーションの表示のみ、保存しない）を簡潔に説明する

## 未決事項

- 実際に使用する具体的な素材・ツールが確定した時点で、個別にライセンス内容を確認し、本ドキュメントに記録する
- プライバシーポリシーの簡易注記ページの具体的な文面 → ワイヤーフレーム作成時
