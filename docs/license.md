# ライセンス・法務面の方針

## 利用素材のライセンス確認

本サイトでは以下の外部素材・ツールを利用する想定であり、いずれも**利用前にライセンス・商用利用可否を本人が確認する**。

| 素材・ツール                     | 用途                                                                | 確認事項                                                                                                 |
| -------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| LottieFiles（無料素材）          | 特定の日の主役キャラクター演出（`feature/background-animation.md`） | 商用利用可否、クレジット表記義務の有無                                                                   |
| AI画像生成ツール（Midjourney等） | OG画像・背景イラスト（`feature/og-image.md`）                       | 生成物の商用利用・公開可否（利用するツールの規約は都度変わるため、制作開始前に必ず最新の規約を確認する） |

## クレジット表記

- クレジット表記は、**利用する素材のライセンスが表記を義務付けている場合のみ**、フッター等に軽く記載する
- 専用のクレジットページは設けない（MVPの範囲外）

## 未決事項

- 実際に使用する具体的な素材・ツールが確定した時点で、個別にライセンス内容を確認し、本ドキュメントに記録する
- プライバシーポリシー・利用規約ページの要否（位置情報・Cloudflare Web Analytics等を扱うため、最低限の記載は検討が必要）
