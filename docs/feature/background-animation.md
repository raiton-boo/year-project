# 背景アニメーション（天候・天体連動）

## ステータス

検討中

## 概要

単なる色の装飾ではなく、ユーザーの位置・現在時刻・実際の天候・季節/特定の日に連動した、生きた背景アニメーションを実装する。

- 太陽・月の位置を、実際の日の出・日の入り時刻に基づいてリアルタイムに動かす
- ユーザーの位置情報の天候（晴れ/曇り/雨/雪/雷など）を反映する
- 季節・時期・特定の日に応じた演出（桜吹雪、花火、落ち葉、雪など）を重ねる

## 位置情報の取得

- **デフォルト**: Cloudflare Workersが`request.cf`で提供するIPベースの位置情報（国・都市・緯度経度・タイムゾーン）を使用する。許可プロンプトは不要で、全ユーザーが体験できる
- **アップグレード**: ユーザーがブラウザのGeolocation APIを許可した場合は、より正確な位置情報で上書きする
- 位置情報が取得できない場合のフォールバック（デフォルト地域）は実装時に決定する

## 太陽・月の位置アニメーション

- 緯度経度・現在時刻から日の出・日の入り時刻を天文計算で算出し（外部API不要、ライブラリ利用を想定）、太陽/月をその時刻に応じた空の位置にアニメーションさせる
- 時間帯によって太陽が沈み、月が昇るような自然な動きを表現する（`feature/dark-mode.md`の「時間によって同期」モードとも連動する想定）

## 天候アニメーション

### データソース

- **Open-Meteo**（無料・APIキー不要の天気API）を想定
- Cloudflare Workers経由でAPIを呼び出し、取得した天候データをレスポンスに利用する（APIキー管理が不要なため、シークレット管理の負担も小さい）

### 表現する天候の種類

- **第1段階**: 大まかな5種類（晴れ・曇り・雨・雪・雷）に対応するアニメーションを用意する
- **第2段階（将来拡張）**: より細かい天気コード（霧・あられ等）に対応する

### 更新頻度・キャッシュ戦略

- **4時間単位**で天候データを更新する
- 地域（緯度経度を一定単位に丸めたキー等）ごとにCloudflareのエッジキャッシュを効かせ、同一地域からの大量アクセスでAPI呼び出し回数が増えないようにする（`feature/og-image.md`の日付単位キャッシュと同じ考え方）

## 季節・特定の日の演出

`feature/messages.md`の季節区分・節目メッセージ、`feature/og-image.md`の特別な日と連動し、2種類の演出を組み合わせる。

1. **背景に漂う軽い装飾（tsParticlesの絵文字/画像シェイプ）**: 桜吹雪（春）・落ち葉（秋）・雪（冬）など、画面全体にさりげなく漂う粒子表現
2. **主役となるキャラクター演出（Lottie）**: 雪だるま・スイカ・かぼちゃなど、特定の日に登場する主役級のアニメーション。[LottieFiles](https://lottiefiles.com/)の無料素材をそのまま利用し、自前でのイラスト制作は行わない

年末年始期間、ハロウィン・クリスマス等の特別な日は、上記を組み合わせた専用の演出にする。

## レイヤー構成（イメージ）

1. 空のグラデーション（時間帯・太陽/月の位置で変化）
2. 太陽・月（軌道アニメーション）
3. 天候パーティクル（雨・雪・雲など、tsParticles）
4. 背景に漂う軽い季節装飾（桜・落ち葉など、tsParticlesの絵文字/画像シェイプ）
5. 特定の日の主役キャラクター演出（雪だるま・スイカ・かぼちゃなど、Lottie）

具体的な技術選定（CSS/SVG/tsParticles/Lottieの使い分け）は`tech-stack.md`を参照。
