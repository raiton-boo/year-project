# タブタイトル・favicon動的更新

## ステータス

検討中

## 概要

ブラウザタブを見るだけで残り日数がわかるように、`document.title`をリアルタイムで更新する。faviconは季節テーマに応じて切り替える。

## タブタイトル

- `document.title`に残り日数を含める（例: `あと65日 | サイト名`）
- 更新頻度はカウントダウン表示の更新頻度に準じる想定（実装時に確定。タブはバックグラウンドでも動くため、過度な高頻度更新は避ける）
- SEOの動的title/description要件（`requirements.md` 4.2）とは別軸。あちらはページ初回読み込み時のメタタグ、こちらはクライアントサイドでのタブ表示の話

## favicon

- 数字バッジの動的描画は16x16pxでは視認性が低いため行わない
- 代わりに、`feature/messages.md`の季節区分（四半期＋気象学的季節）に連動して、favicon自体を季節テーマのアイコンに切り替える
- 具体的なアイコンデザインはワイヤーフレーム作成時に決定する
