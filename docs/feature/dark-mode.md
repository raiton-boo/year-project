# ダークモード対応

## ステータス

検討中

## 概要

ライト/ダークの2テーマに加え、システム設定との同期・時間帯による自動切り替えを含めた4パターンのモード選択を提供する。切り替え時は太陽が沈む・月が昇るようなアニメーションを伴う。

## モード一覧

ユーザーが以下4つから選択できる。

1. **システムと同期**: OS/ブラウザの`prefers-color-scheme`に従う
2. **ライトモード固定**
3. **ダークモード固定**
4. **時間によって同期**: 固定時刻を基準に自動でライト/ダークを切り替える

選択結果は保存し、次回訪問時も維持する（`localStorage`を想定。`feature/countdown.md`の表示単位設定と同様の方式）。

## 「時間によって同期」の切り替え基準

- 固定時刻で判定する（具体的な時刻はワイヤーフレーム作成時に決定。例: 18:00〜6:00はダーク）
- サイトを開いたまま切り替え時刻を迎えた場合も、リロードなしでリアルタイムに切り替わる

## 切り替え時のアニメーション

- 太陽が沈む・月が昇るようなイメージの演出アニメーションを、motionで実装する
- 「時間によって同期」モードで自動的に切り替わる時だけでなく、設定画面でユーザーが手動でモードを切り替えた時も同じアニメーションを再生する
- 具体的な演出内容は、背景イラストのデザインが固まるワイヤーフレーム作成時に合わせて決定する
