# プログレスバー

## ステータス

検討中

## 概要

その年（1/1 00:00:00 〜 12/31 23:59:59）の経過率を示す単一のプログレスバー。横長バー／リング型の2形状をユーザーが切り替え可能で、ピンチ操作による連続ズームで表示精度を変えられるインタラクティブな機能として実装する。

## 形状

- **横長バー（オーソドックス）**と**リング型（円形ゲージ）**の両方を実装し、ユーザーが切り替えられるようにする
- 切り替えUIの配置はワイヤーフレーム作成時に決定する

## 色

- `feature/messages.md`の季節メッセージ（四半期区分・気象学的季節の言葉）と連動し、季節ごとに自動でテーマカラーが変わる
  - 例: 冬寄りの時期は寒色系、夏寄りの時期は暖色系 など、具体的な配色はワイヤーフレーム作成時に決定する

## ピン（現在位置マーカー）

- バー上の現在の進捗位置に、常に表示されるピン（マーカー）を置く
- ピンのそばに進捗率を数値表示する
- 通常時は整数%表示（例: `82%`）

## ズーム機能

バーの一部を拡大し、より細かい進捗率の変化をリアルタイムに視認できるようにする。

### 背景（なぜズームが必要か）

1年は約3,153万6,000秒あり、1秒あたりの進捗率の変化は約0.0000032%しかない。整数%表示のままでは「動いている感」が全く伝わらないため、ズームして小数点以下の桁を表示することで、1秒単位の変化が視認できるようにする。

### 操作方法

- **トラックパッド/スマホ**: ピンチイン・ピンチアウト
- **PC（マウス）**: Ctrl＋ホイール
- 誤操作を避けるため、+/−ボタンは設置しない

### ズーム段階と表示桁数

6段階以上で、ズームするほど小数点以下の桁数が増え、滑らかに精度が上がっていく。

| ズームレベル | 小数点以下の桁数 | 表示例       |
| ------------ | ---------------- | ------------ |
| Lv.1（通常） | 0桁（整数）      | `82%`        |
| Lv.2         | 1桁              | `82.3%`      |
| Lv.3         | 2桁              | `82.34%`     |
| Lv.4         | 3桁              | `82.345%`    |
| Lv.5         | 4桁              | `82.3456%`   |
| Lv.6（最大） | 6桁              | `82.345678%` |

- Lv.6（最大ズーム）では、バー表示自体も画面いっぱいに拡大され、現在位置付近だけが見える状態になる。小数点以下6桁まで表示することで、1秒ごとに最後の桁が変化し「進んでいる」ことが明確にわかる
- 更新頻度は1秒ごと

## ページ読み込み時のアニメーション

- 初回表示時、バーが0%から現在の進捗率までイージングで滑らかに伸びるアニメーションを再生する（motionで実装）
