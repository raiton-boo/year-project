# 時期によって変わる文言（メッセージ表示）

## ステータス

検討中

## 概要

ページ内に表示される文言は、常時表示される「通常メッセージ」と、特定の残り日数に到達した瞬間だけ出る「節目メッセージ」の2層構造で構成する。

- **通常メッセージ**: 四半期（季節）ごとに切り替わる、日常的な文言
- **節目メッセージ**: 残り日数が特定の節目に到達した日だけ表示される、特別な文言＋演出（パーティクル爆発等、アニメーション要件を参照）

表示位置（カウントダウン上部の見出し / 下部の補足など）は、ワイヤーフレーム作成時に決定する。

## トーン

カジュアル・親しみやすい ＋ ユーモア・ネタ系。堅苦しい表現は避ける。

## 通常メッセージ（季節文言）

- **切り替え単位**: 四半期（Q1: 1〜3月 / Q2: 4〜6月 / Q3: 7〜9月 / Q4: 10〜12月）の4回
- **言葉選び**: 気象学的季節（春・夏・秋・冬）の言葉を使う
  - 例: Q1の文言では「寒さも峠を越えて、春が近づいてきた！」のように、気象学的な季節感を織り交ぜた表現にする
- 具体的な文言内容はワイヤーフレーム作成時に確定する

## 節目メッセージ

### 節目の日数

残り日数が以下に到達した日。

- 300日
- 200日
- 100日
- 1ヶ月（30日）
- 1週間（7日）
- 3日
- 1日

### 表示期間

到達日の1日間のみ表示する。翌日になると通常メッセージ（または他の優先ルール）に戻る。

### 演出

節目到達時はパーティクル爆発などの特別アニメーションと合わせて表示する（詳細は`feature/animation.md`等、今後整理）。

## 年末年始の特別メッセージ

`requirements.md`で定義した年末年始期間（12/25〜翌年1/3）中は、専用の文言・演出にする。

## 優先度ルール

複数の条件が重なった場合、以下の優先順位で表示する文言を決定する。

1. **年末年始メッセージ**（最優先）
2. **節目メッセージ**（該当日のみ）
3. **通常メッセージ（季節文言）**（上記に該当しない場合のデフォルト）
