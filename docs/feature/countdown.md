# 残り時間表示（カウントダウン）

## ステータス

検討中

## 概要

その年の12/31 23:59:59までの残り時間を表示する。残り日数に応じて表示単位が自動的に切り替わり、ユーザーは任意のタイミングで表示パターンを手動選択することもできる。

## 表示単位

4パターンを用意する。

1. 日のみ（例: `あと123日`）
2. 日＋時間（例: `あと30日12時間`）
3. 日＋時間＋分（例: `あと7日3時間15分`）
4. 日＋時間＋分＋秒（フル表示。例: `あと1日2時間3分4秒`）

## 自動切り替えの閾値

「1ヶ月・1週間・1日」を基準に、残り日数が少なくなるほど細かい単位に自動で切り替わる。

| 残り時間の範囲             | 自動表示パターン                          |
| -------------------------- | ----------------------------------------- |
| 残り31日以上               | 1. 日のみ                                 |
| 残り8日〜30日              | 2. 日＋時間                               |
| 残り1日〜7日（24時間以上） | 3. 日＋時間＋分                           |
| 残り24時間未満             | 4. 日＋時間＋分＋秒（**固定・切替不可**） |

## 手動切り替え

- 残り24時間以上の間は、ユーザーが上記4パターンから自由に表示を選択できる（自動判定を手動で上書きする形）
- 選択結果は`localStorage`に保存し、次回訪問時も同じ表示パターンを維持する
- **残り24時間を切ったら、手動切り替えUIごと無効化し、強制的にパターン4（日＋時間＋分＋秒）に固定する**
  - 切替UI自体を非表示にするか、disabled状態にするかはワイヤーフレーム作成時に決定する

## 年をまたいだ瞬間の挙動

- 1/1 00:00:00に到達した際の挙動（翌年のカウントへの自動切り替え、新年メッセージ表示など）は別途検討する
- 本ドキュメントのスコープ外。`feature/messages.md`（年末年始の特別演出）と合わせて検討する
