# 予算試算

## 前提

- Cloudflareの料金体系は変更されることがあるため、ここでの数値は**概算**。実装・契約前に[Cloudflareの最新料金ページ](https://developers.cloudflare.com/workers/platform/pricing/)で必ず確認すること
- 為替レートは概算（$1 ≒ 150円）で計算

## 必要なプラン: Cloudflare Workers Paid（$5/月）

Freeプラン（Workers Free）はリクエストあたりのCPU時間が10msに制限されており、OG画像生成（`next/og`によるSatoriレンダリング）がこの上限を超える可能性が高い。そのため**Paidプラン（$5/月 ≒ 750円/月）が実質必須**と判断する。

Paidプランに含まれる主な無料枠（概算）:

- リクエスト数: 1,000万回/月
- CPU時間: 3,000万ms/月
- 超過分: リクエスト $0.30/100万回、CPU時間 $0.02/100万ms

## サービスごとの費用

| サービス                 | 用途                                                              | 想定コスト                                                                                  |
| ------------------------ | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Cloudflare Workers       | ホスティング・OG画像生成・天候API中継                             | $5/月（Paidプラン基本料金）                                                                 |
| Cloudflare KV            | 累計訪問者数・アーカイブスナップショット                          | 基本的に無料枠内（詳細は下記「コスト上の注意点」参照）                                      |
| Cloudflare R2            | OG画像・シェア画像用の背景イラスト保存                            | ほぼ$0（数十枚の小さい画像のみ。保存容量・読み取り回数ともに無料枠内）                      |
| Cloudflare Web Analytics | アクセス解析                                                      | $0（無料）                                                                                  |
| Cloudflare Cron Triggers | アーカイブスナップショット生成                                    | $0（無料）                                                                                  |
| Open-Meteo               | 天候データ取得                                                    | $0（無料・APIキー不要）                                                                     |
| ドメイン                 | 独自ドメインは取得せず、`*.workers.dev`のデフォルトドメインを利用 | $0                                                                                          |
| AI画像生成ツール         | OG/背景用イラストの事前生成（一時的な利用）                       | 利用するツール次第（例: Midjourney 等 月$10前後。生成作業が終われば契約を続ける必要はない） |

## 月額の目安

- **通常時**: 約$5〜7/月（約750〜1,000円/月）
- **バズって一時的にアクセスが急増した場合**（例: 月間5,000万リクエスト程度を想定）
  - リクエスト超過分: 約4,000万回 × $0.30/100万 ≒ $12
  - CPU時間は、OG画像・天候APIの結果をキャッシュする設計（日付単位・地域単位でのエッジキャッシュ）のため、リクエスト数ほど線形には増えない想定
  - 合計で**月$20〜40程度（約3,000〜6,000円）**に収まる見込み

## コスト上の注意点

- **累計訪問者数カウンター（`feature/visitor-counter.md`）は、ページ表示のたびにKVを読みに行く実装だと、バズった際にKV読み取り回数が急増しコストが跳ねるリスクがある。** 表示用の値は数十秒〜数分程度のエッジキャッシュを挟み、KVへの直接読み取り回数を抑える設計にすることを推奨する（他の機能で既に採用している「日付・地域単位のキャッシュ」と同じ考え方）
- OG画像・天候データは既にキャッシュ戦略が決まっているため、アクセス急増時のコスト増を抑えやすい
